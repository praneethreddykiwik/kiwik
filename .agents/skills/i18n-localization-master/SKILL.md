# i18n Internationalization & Localization Guide
- Next-Intl / react-i18next locale-based route resolution (`/en/`, `/es/`, `/fr/`).
- RTL (Right-to-Left) CSS layout support via `dir="rtl"`.
- Native `Intl.DateTimeFormat` and `Intl.NumberFormat` for dates and currencies.
