# End-to-End Web Application Architect Guide

## Architectural Blueprint
1. **Frontend**: Next.js App Router / Vite React SPA with Tailwind CSS, Framer Motion, and Radix UI.
2. **State & CMS**: Zustand store persistent state & local database CMS synchronization.
3. **Backend & DB**: Server Actions / Route Handlers connected to Neon Postgres / Prisma / Drizzle with Zod validation.
4. **Security & Performance**: Zero-trust API validation, CSP headers, rate limiting, and 100 Lighthouse optimization built-in from line 1.
