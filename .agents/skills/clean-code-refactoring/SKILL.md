# Clean Code & SOLID Architecture Guide

## Core Principles
1. **Single Responsibility (SRP)**: Each component, module, or function should do one thing well.
2. **Open/Closed (OCP)**: Extend behavior through composition without mutating existing tested core logic.
3. **DRY & KISS**: Eliminate duplicate logic while avoiding over-engineering simple solutions.
