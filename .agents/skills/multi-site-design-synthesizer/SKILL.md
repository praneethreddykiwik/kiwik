# Multi-Website Design Synthesizer Guide

## Synthesis Methodology
1. **Multi-Source Inspiration**: Never copy a single template. Extract typography hierarchy from Linear, glassmorphism from Apple/macOS, micro-interactions from Stripe, and grid spacing from Vercel.
2. **Unified Design Tokens**: Merge color palettes, font pairings, and shadow scales into a cohesive Tailwind `@theme` system.
3. **Originality Guarantee**: Build tailored UI components that combine top visual aesthetics into a net-new, custom digital product experience.
