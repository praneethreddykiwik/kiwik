# Tailwind CSS Master Guide

## Best Practices
- Enforce Tailwind CSS v4 `@theme` configuration in `globals.css`.
- Avoid arbitrary inline values (`w-[317px]`) when standardized tokens (`w-80`) exist.
- Use `cn()` helper to safely combine dynamic component class names.
