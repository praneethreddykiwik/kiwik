# Glassmorphic Visual Design Guide

## Glassmorphism Recipe
- Background: `bg-white/5 dark:bg-zinc-900/80`
- Backdrop Blur: `backdrop-blur-xl sm:backdrop-blur-2xl`
- Border: `border border-white/10 dark:border-white/15`
- Shadow & Glow: `shadow-[0_20px_50px_rgba(0,0,0,0.4)] hover:border-emerald-500/30`
